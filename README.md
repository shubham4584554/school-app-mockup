# The Academy — 30 Screen Client Demo

Built directly from the uploaded `school app.zip`.

- Exactly 30 screens (01–30).
- Original PNG files copied into `assets/`.
- One static HTML page per screen.
- Native HTML links; no JavaScript.
- Click a screen to follow its main flow.
- Previous / Next navigation on every screen.
- Screen-map landing page.
- `START_DEMO.bat` launches a local server on Windows.

IMPORTANT: Extract the ZIP before opening it so the `assets` folder remains beside the HTML files.
